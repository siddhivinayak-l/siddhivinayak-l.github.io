# Search visibility setup for Siddhi Vinayak Pandey

Upload these four files to the root of the GitHub Pages repository:

- `index.html`
- `robots.txt`
- `sitemap.xml`
- `siddhi-vinayak-pandey.jpg`

The page now declares `https://siddhivinayak-l.github.io/` as its canonical address. If the public
website address changes, replace that address in all four files before upload.

## Complete these steps after deployment

1. Open [Google Search Console](https://search.google.com/search-console/) and
   add the URL-prefix property `https://siddhivinayak-l.github.io/`.
2. Choose the HTML-tag verification method. Add the verification tag to the
   `<head>` of `index.html`, deploy it, and click Verify. The tag is unique to
   your Google account and therefore is not included in this package.
3. Submit `https://siddhivinayak-l.github.io/sitemap.xml` in Search Console.
4. Inspect `https://siddhivinayak-l.github.io/` in Search Console and select **Request indexing**.
5. Keep the Google Scholar profile public and add `https://siddhivinayak-l.github.io/` as the homepage.
   Retain the verified University of Manchester email on the Scholar profile.
6. Add the same website URL to ORCID, LinkedIn, GitHub and any University of
   Manchester or research-group profile. Use the exact name “Siddhi Vinayak
   Pandey” consistently.
7. Ask the university group page and collaborators' institutional pages to link
   to this website where appropriate. Relevant institutional links are stronger
   signals than repeating keywords on the page.

Google decides when and how a page appears, so no metadata can guarantee a
particular ranking. Search Console will show whether the page is indexed and
which queries bring impressions.
